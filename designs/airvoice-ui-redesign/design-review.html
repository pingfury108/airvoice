空音输入法 · UI 重设计

基于现有功能结构（语音面板 / 按键面板 / 横屏悬浮胶囊）做三个风格的完整演绎。所有方向保持品牌资产：靛蓝 #3D5AFE、「胶囊 + 声波」logo DNA、按住说话的核心交互。图标从 emoji 升级为统一线性图标。

方向 A · 求稳：现有风格精修 方向 B · 求质感：OLED 暗色 方向 C · 求品牌：声波胶囊
方向 A

精工蓝 · 进化版 Material

现有风格的系统化精修：统一 6px 键距网格、13px 键角半径、单层细阴影；工具行 emoji 换成同光学尺寸的线性图标；回车键保持次强调蓝底。零学习成本，第一眼就是"现在的空音，但更干净"。

方向 B

墨夜 · OLED 暗色

深色键盘在 AMOLED 上省电、夜间打字不刺眼，也是当前主流输入法的第二主题标配。品牌靛蓝在暗色下提亮为 #7C93FF 保对比度；麦克风键带品牌色泛光，成为整块键盘唯一的发光体——视觉焦点天然落在核心交互上。

方向 C

声波胶囊 · 品牌 DNA 前置

把 logo 的「胶囊 + 声波」变成整个键盘的视觉语言：全部键改为胶囊形，麦克风成为一支纵向大胶囊——品牌圆环托麦克风、底部嵌入声波律动条，状态文字收进胶囊内部，独立状态行取消（少一行 chrome，主区更高）。语言选择做成工具行首位的胶囊芯片键，点按循环切换（自动→中文→粤语→English），不再需要去设置页。

组件

横屏悬浮胶囊 · 三方向对比

同一结构（主键 🎤 + 次键 ⌫ 竖排圆），三方向各自的材质表达。交互不变：点按录音、拖动移位、长按收起。

说明：以上为高保真静态稿，键位布局与现版功能一一对应（未增删功能）。录音中状态 = 麦克风变红（B 方向红光），识别中变橙；A/B 方向状态行文字随之变化，C 方向由胶囊内声波条动画表达。选 定方向后我按该 token 体系落实布局 XML 与配色，约半天工作量。
